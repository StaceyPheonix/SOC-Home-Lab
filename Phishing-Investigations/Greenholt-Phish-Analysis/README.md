# Greenholt Phish Investigation

## Overview
This case study documents the analysis of a suspected phishing email submitted to a Security Operations Center (SOC). The investigation focused on email header analysis, sender authentication validation, IOC extraction, attachment analysis, and threat intelligence research.

## Scenario
A Greenholt PLC employee reported a suspicious email from a known customer. The message contained unusual financial transfer instructions and an unsolicited attachment.

## Investigation Objectives

- Analyze email metadata and headers
- Identify indicators of compromise (IOCs)
- Validate sender authenticity
- Analyze attachment characteristics
- Determine phishing classification
- Document SOC response recommendations

## Tools Used

- Email header analysis
- VirusTotal
- SPF/DKIM/DMARC analysis
- SHA256 hashing
- Threat intelligence research
- MITRE ATT&CK Framework

## Investigation Outcome

The email was determined to be a suspected phishing attempt involving social engineering, sender impersonation indicators, and a suspicious attachment.
